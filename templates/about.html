B.Sc Data Science Project

Smart Nutrition Analyzer & Personalized Diet Recommendation System

An applied Data Science and Machine Learning project exploring nutritional data analysis, classification modeling, and content-based recommendation heuristics.

1. Project Objectives

The goal of this system is to bridge everyday wellness nutrition with reproducible Data Science methods:

  • Energy Assessment: Estimate daily caloric requirements based on validated physiological formulas (Mifflin-St Jeor).
  • Screening: Compute Body Mass Index (BMI) as an accessible population screening metric.
  • Machine Learning Profile Classification: Categorize user nutritional intake into structured classes (Balanced, High Calorie Intake, Low Nutrition Intake) using a Scikit-learn Random Forest Classifier.
  • Personalized Recommendation: Suggest realistic, balanced food choices tailored to user dietary restrictions (Vegetarian/Non-Vegetarian) and fitness goals.
2. Mathematical & Physiological Formulas
Body Mass Index (BMI)

The standard WHO anthropometric screening ratio:

BMI = Weight (kg) / (Height (m))²
• < 18.5: Underweight
• 18.5 – 24.9: Normal weight
• 25.0 – 29.9: Overweight
• ≥ 30.0: Obese
Basal Metabolic Rate (Mifflin-St Jeor)

Considered the most accurate BMR formula for healthy adults:

Men: 10×W + 6.25×H - 5×Age + 5
Women: 10×W + 6.25×H - 5×Age - 161
TDEE = BMR × Physical Activity Factor (1.2 to 1.9)
3. Machine Learning Architecture
Algorithm: Random Forest Classifier

A Random Forest ensemble combines multiple decision trees trained on bootstrap samples with random feature subsampling. This prevents overfitting and captures non-linear interactions among nutritional features.

Parameter Value Data Science Rationale
Estimators (Trees) 100 Provides variance reduction without excessive inference latency.
Max Depth 6 Prevents tree memorization and maintains explainability.
Input Features Age, BMI, Daily Calories, Protein, Carbs, Fat, Fiber Avoids target leakage; captures the multidimensional lifestyle profile.
Target Classes Balanced, High Calorie Intake, Low Nutrition Intake Clearly defined, non-clinical categories for lifestyle screening.
